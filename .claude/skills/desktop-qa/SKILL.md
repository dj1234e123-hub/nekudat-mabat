# SKILL: בדיקת מראה (מחשב וטלפון)

בעל הפרויקט עובד מהטלפון ולא רואה את המחשב. הסקיל הזה הוא העיניים שלו.

## לפני כל דבר
קרא `docs/DESKTOP-DESIGN.md` (הכללים הקבועים). אין להמציא כללים חדשים בלי להציג אותם לאישור.

## הרצה
1. `npm run build` ואז `npm run preview` ברקע (פורט 4321).
2. `npm run qa:visual -- --out <scratchpad>/qa` (13 עמודים × 390/1280/1920, עברית וספרדית).
   - אם Playwright חסר: `npm i --no-save playwright` (לא נכנס ל-package.json), או גלובלי.
   - נגד האתר החי: `npm run qa:visual -- https://nekudatmabat.blog` (לפעמים חסום בסנדבוקס; ב-GitHub Actions עובד).
3. הסקריפט בודק אוטומטית: גלישה, שגיאות JS, תמונות שבורות, כותרת צרה, ניווט מלא בלי ☰ במחשב, מדף חתוך.
4. **ואז לפתוח בעין** לפחות: דף בית, סיפור וסיפורים ב-1280 (הצילומים נשמרים). הסקריפט לא שופט יופי.

## מה להחזיר לבעל הפרויקט
- שורה: "תקין" או כמה בעיות.
- לכל בעיה: איפה (עמוד ורוחב), מה רואים, תיקון מוצע בשורה אחת. בלי עברית טכנית.
- תיקון קוד רק אחרי אישור (כלל 1 ב-CLAUDE.md), ואז: build, `check:moments`, qa:visual, מיזוג לראשי.

## כשהבדיקה האוטומטית בגיטהאב נכשלה
ב-Issues בריפו יש Issue בשם "בדיקת מראה נכשלה" עם הפירוט. לקרוא אותו, להריץ מקומית, ולהציע תיקון.

## עדכון
בעיה חדשה מסוג שלא נתפס: להוסיף בדיקה ל-`scripts/qa-visual.mjs` ושורה ל-`docs/DESKTOP-DESIGN.md`.
