# מסמך אפיון — "נקודת מבט"

> סטטוס: **ממתין לאישור בעל הפרויקט**
> נכתב: 2026-08-20 · מבוסס על שיחת אפיון מלאה. כל שינוי במסמך זה טעון אישור.

## 1. מהות ומטרה

אתר שהוא ספרייה חיה של סיפורים בעברית. כל סיפור מוביל את הקורא למסע שקט אל נקודת מבט חדשה.

האתר הוא מקום שקט שאפשר לעצור בו לכמה דקות ולקרוא — לא אתר עמוס, לא צבעוני מדי, לא אתר חדשות. הסיפור והמסר הם המרכז; העיצוב משרת את התוכן.

האתר עובד יחד עם קהילת הוואטסאפ של "נקודת מבט": קוראים משתפים סיפורים הלאה ומצטרפים לקבוצה.

## 2. קהל ותרחיש שימוש מרכזי

- קוראי עברית, רובם מגיעים **מהטלפון** (לרוב דרך קישור בוואטסאפ).
- תרחיש מרכזי: אדם מקבל קישור לסיפור → פותח בטלפון → קורא בנוחות וברצף → משתף הלאה או מצטרף לקבוצה או ממשיך לסיפור נוסף.

## 3. תוכן

### מבנה סיפור
כל סיפור הוא קובץ Markdown באוסף תוכן של Astro, עם השדות:

| שדה | חובה | תיאור |
|------|------|--------|
| `title` | כן | כותרת הסיפור |
| `topic` | כן | נושא (אחד מרשימת נושאים מוגדרת) |
| `cover` | כן | תמונת שער |
| `date` | כן | תאריך פרסום (למיון מהחדש לישן) |
| `excerpt` | כן | תקציר קצר — לתצוגה ברשימות ובתצוגה המקדימה בשיתוף |
| גוף הקובץ | כן | טקסט הסיפור (Markdown) |

- טקסט ותמונת שער בלבד; ללא אודיו/וידאו.
- רשימת הנושאים תיקבע עם בעל הפרויקט לפני העלאת התוכן הראשון, וניתנת להרחבה.

### תהליך הוספת סיפור
בעל הפרויקט שולח סיפור (טקסט + תמונת שער + נושא) בצ'אט → Claude יוצר את הקובץ, דוחף ל־GitHub → Vercel מפרסם אוטומטית. אין ממשק ניהול ואין צורך של בעל הפרויקט לגעת בקוד.

## 4. מבנה האתר (עמודים)

| עמוד | תוכן |
|-------|-------|
| **בית** | כניסה שקטה לאתר: הצגת הסיפורים (מהחדש לישן), גישה לנושאים, כפתור "סיפור אקראי", קישור לקבוצת הוואטסאפ |
| **עמוד סיפור** | חוויית הקריאה עצמה — הלב של האתר. כותרת, תמונת שער, טקסט נוח לקריאה, כפתור שיתוף, ובסוף: הזמנה שקטה לקבוצה / לסיפור נוסף |
| **עמוד נושא** | כל הסיפורים בנושא מסוים |
| **אודות** | קצר ופשוט: מי מאחורי האתר ומה הרעיון של "נקודת מבט" |
| **404** | עמוד שגיאה עדין שמחזיר לסיפורים |

**סיפור אקראי** — כפתור שמוביל לסיפור אקראי, ברוח "מסע אל נקודת מבט חדשה".

## 5. שיתוף וקהילה (דרישה מרכזית)

1. **כפתור שיתוף בכל סיפור**, בדגש על וואטסאפ (בנוסף: העתקת קישור ושיתוף כללי של המכשיר).
2. **תצוגה מקדימה איכותית בשיתוף**: כל עמוד סיפור כולל תגיות Open Graph מלאות — כותרת, תקציר ותמונת השער — כך שקישור משותף בוואטסאפ נראה מזמין.
3. **קישור בולט להצטרפות לקבוצת הוואטסאפ** של "נקודת מבט" (בעל הפרויקט יספק את הקישור לפני שלב הבנייה הרלוונטי).

## 6. עיצוב

### אווירה
חם, רגוע, עמוק ונקי — "כמו לפתוח ספר טוב במקום שקט". שילוב של ספר מודרני, יומן אישי ומקום שקט למחשבה. העיצוב לעולם לא גונב תשומת לב מהתוכן.

### צבעים
בסיס בהיר בגוונים חמים ועדינים (נייר/שמנת). צבעי המותג כנגיעות עדינות ומדויקות בלבד:

| צבע | קוד |
|------|------|
| אדום עמוק | `#B0463B` |
| ירוק־כחול | `#1F5C57` |
| כחול עמוק | `#003B5C` |
| זהב חם | `#C9A24D` |
| שמנת | `#F3E9D3` |

### טיפוגרפיה
- טקסט גדול יחסית, ריווח שורות נדיב, כותרות ברורות; נוחות קריאה מהטלפון בראש סדר העדיפויות.
- **החלטה סופית (נבחרה בהשוואה חזותית):** Frank Ruhl Libre לכותרות/ציטוטים; **Heebo** לטקסט השוטף ולממשק.
- שפת הממשק: עברית בלבד ככל האפשר — מינימום מילים באנגלית.

### מותג
- לוגו: עין ספירלית בצבעי המותג (src/assets/logo.jpg), מוצג בראש כל עמוד.
- סלוגן: "שמים את הנקודה במרכז". בעלים: אפרים עטיה.
- עמוד האודות יכלול תמונה אישית של אפרים (תועלה בשלב 4).

### כללי
- עברית, RTL מלא.
- Mobile-first: מעוצב קודם לטלפון, ומתרחב יפה למסך גדול.
