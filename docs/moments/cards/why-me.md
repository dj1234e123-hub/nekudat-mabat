# כרטיס חוויה: "למה דווקא אני?"

**היחידה:** למה זה קורה לי · **מצב:** טיוטות, ממתין להכרעה · **מסלול:** מקוצר, לבקשת בעל הפרויקט (שלוש טיוטות ישר, 2026-11-08)

## למה דווקא עכשיו

**מקור: עריכתי + פער-במפה.** בעל הפרויקט ביקש רגעים לשאלה שעולה אצל מי שעובר כאב או מסע קשה. בקורפוס יש "שני משפטים" (זה עונש / שכחו אותי), אבל אין רגע על השאלה עצמה, ואין רגע שנשאר איתה בלי סיבוב, ואין רגע לזה ששואלים אותו אותה. שלוש הטיוטות הן שלוש תנועות שונות: החזקה, עיני האחר (מבפנים), ונוכחות מול שואל.

## מוקשים (נקראו לפני הכתיבה)

- לא מסבירים למה סבל קורה, לא "הכול לטובה", לא "ניסיון", לא "יסורי אהבה". הרגע לא מוסיף אמת.
- לא מציגים את השאלה כטעות או כחוסר אמונה. היא נשארת שאלה אמיתית.
- בלי "אתה" ובלי בינוני זכר אל הקורא. בלי מקף גדול.

## הטיוטות

### א׳ · אל התקרה · כאב · החזקה בלי סיבוב

```
feeling: pain
title: אל התקרה
handle: |-
  בלילה שהיא חוזרת,
  לא למהר לסגור אותה.
```

בשלוש בלילה / השאלה חוזרת. / קודם בכעס, / אחר כך **בעייפות**.

ואז כבר בלי קול, / כמו מי ששואל / את התקרה / ויודע שהיא **לא** עונה.

אפשר לא להשיב לה. / אפשר לא למצוא לה סיבה. / אפשר רק להישאר, / **ער** איתה.

--- מותר לשאול שוב, / גם בלילה השלישי.

### ב׳ · השאלה השנייה · כאב (כניסה נוספת: אשמה) · עיני האחר

```
feeling: pain
title: השאלה השנייה
handle: |-
  לשמוע אותה היום
  כאילו חבר שאל.
```

עומדים במסדרון, / והשאלה יוצאת לבד: / למה **דווקא** אני. / ואין מי שעונה.

ואז נכנסת השנייה, / השקטה יותר. / אם זה דווקא, / אז משהו **עשיתי**.

אבל כשחבר שואל / את אותה שאלה, / לא מתחילים לחפש / מה הוא **עשה**.

--- אצל חבר, זה כאב. / אצלך, זה נשמע כמו חשבון.

### ג׳ · למה דווקא הוא · עצב · נוכחות (הצד של מי שנשאל)

```
feeling: sadness
title: למה דווקא הוא
handle: |-
  לשבת ליד מי ששואל,
  גם כשאין מה לענות.
```

אדם קרוב שואל, / בשקט, באמצע ערב: / למה דווקא אני. / ואת **התשובה** אין לך.

מחפשים מה להגיד. / כל משפט נשמע קטן, / והשתיקה מתארכת, / ונשמעת כמו **כישלון**.

אבל הוא לא ביקש תשובה. / הוא רק רצה לשאול, / בקול ולא לבד, / ליד מי שלא **יברח**.

--- התשובה לא הייתה אצלך. / ועדיין, נשארת.
