# רשימת בדיקה: סיפור חדש באתר

נכתב 2026-11-03, אחרי העיצוב מחדש של עמוד הסיפורים, עמוד הסיפור ודף הבית. המטרה: כל סיפור שעולה ייראה ויתנהג כמו כל השאר, בלי לסמוך על זיכרון. **הבנייה נעצרת (`npm run check:stories`, רץ לפני כל בנייה) אם חסר hook, נושא או תמונת שער.**

## מה בכל סיפור (קובץ `src/content/stories/<slug>.md`)

| שדה | חובה? | מה |
|---|---|---|
| `title` | כן | שם הסיפור |
| `section` | כן | העולם: `meshalim` · `tzadikim` · `yoman` · `chaim`. הכלל: מי זה קרה לו? |
| `date` | כן | **שעת ההעלאה בפועל** (UTC). תאריך עתידי = הסיפור לא נבנה עד אז |
| `excerpt` | כן | תקציר בלי לחשוף את הסיום. מופיע בגוגל ובתצוגה המקדימה |
| **`hook`** | **כן (נאכף)** | שאלה שהסיפור עונה עליה, בגוף "אנחנו", עד כ-12 מילים, בלי לחשוף את הסיום. הפיתוי בכל כרטיס, בעמוד הסיפורים, בדף הבית ובסוף כל סיפור |
| **`tags`** | **כן (נאכף)** | לפחות תגית אחת ששייכת לנושא (`src/data/themes.mjs`), או תגית חג (סוכות · שמחת תורה · אחרי החגים). בלי זה הסיפור לא נכנס לשום נושא |
| **`cover` + `coverAlt`** | **כן (נאכף)** | תמונת שער בלי כיתוב ובלי דמויות, וטקסט חלופי. חריג: סיפור מוחזק (תאריך רחוק) |
| `readingTime` | לא | "כ־2 דקות". בלי זה נחשב לפי מילים |
| `featured` | לא | מספר = מוצג בדף הבית הישן. כיום לא בשימוש בעיקר |

## מבנה גוף הסיפור (נאכף ציטוט)

סיפור, **ציטוט אחד** (הפסקה החזקה, ב-`>`, נקודת השיא), תובנה בגוף ראשון, `<div class="story-question">` (שאלה לדרך), חתימה. **הבנייה נעצרת אם אין ציטוט או אם יש יותר מאחד** (בעברית ובספרדית). כמה שורות `>` רצופות נחשבות ציטוט אחד. החריגים היחידים, בהחלטת בעל הפרויקט: 005, 008, 009, 038 (נחתמים בשורה נטויה). תובנה ושאלה לדרך אינן נאכפות: סיפורי שואה, 008, 009, 020, האוהל של הגנן, חלק בעולם הבא, "למה קוראים לי אפרים" נשארים בלי, בכוונה.

## מה קורה לבד (אין מה לעשות)

- הסיפור נכנס לעמוד הסיפורים (חדש, ארכיון, חיפוש, סינון לפי עולם ונושא) ולסוף כל סיפור קרוב ("רוצה עוד?").
- **מספר הצפיות** נמשך מ-PostHog בכל בנייה (`scripts/fetch-views.mjs`), מוצג רק מ-30 ומעלה, וסיפור חדש מקבל "חדש" 10 ימים.
- **"הכי נקראים"** ו"חדש" מתעדכנים לבד.
- **הסיפור המרכזי** בעמוד הסיפורים ובדף הבית הוא האחרון שפורסם. לבחירה ידנית: `src/data/stories-hero.ts`.
- **בנייה יומית** (`.github/workflows/daily-build.yml`) מרעננת את הצפיות.

## ספרדית (מומלץ לכל סיפור, לא נאכף)

חצי מהקריאה בספרדית. קובץ `src/content/stories-es/<אותו-שם-קובץ>.md`, ושורה אחת ב-`src/data/es-slugs.ts` (סלאג ספרדי שנכתב בספרדית, לא תעתיק עברי). `hook` בספרדית **חובה** אם יש תאום. כללי התרגום: `docs/SPANISH-EDITORIAL-GUIDELINES.md`. אותו תאריך ושעה בדיוק בשני הקבצים.

## אחרי כתיבת הקובץ

1. `npm run build`. כולל `check:dashes` (בלי מקף גדול), `check:stories` (hook, נושא, שער) ומשיכת הצפיות. הבנייה אומרת בדיוק מה חסר.
2. דחיפה לענף הראשי `nekudat-mabat`. אם התאריך עתידי: גם התעוררות מתוזמנת שמפעילה פריסה מחדש.
3. הודעה לקבוצה (כלל "שורות עד 4 מילים"). קישורי הקבוצה אומתו מול `site.ts` / `site-es.ts`.
4. לעדכן את `CLAUDE.md` (סעיף הסטטוס) ואת התוכנית הפעילה ב-`docs/stories/`.

## אם משנים את המערכת

- נושא חדש או שינוי בנושא: `src/data/themes.mjs` (שורה אחת, והוראות בראש הקובץ). אחרי שינוי: `npm run check:themes`.
- חג חדש: `src/data/holidays.ts` ועמוד חג, ורשימת תגיות החג ב-`themes.mjs` (`HOLIDAY_TAGS`).
- עיצוב כרטיסים: `StoryTile` · `StoryRow` · `BigTile` · `StoryHero` · `WeekCard`. עיצוב עמוד הסיפור: `src/styles/story.css`, `StoryHeader`, `StoryEnd`.

## קישורי הודעות לקבוצה (סגור)

כל קישור בהודעה לקבוצה נושא `?s=wa-he` (עברית) או `?s=wa-es` (ספרדית). ההחלטה סגורה ואין לשאול עליה. לבדוק שאין טעות הקלדה בתג.
