# עיצוב במחשב: כללים קבועים

נכתב 2026-11-04 (שלב 4.114) מסקירה של 15 סוגי עמודים ב-1280 וב-1920. הטלפון (390) הוא נקודת המוצא; המחשב אינו אתר נפרד אלא אותה חוויה שנושמת ברוחב.

## רוחבים
| רכיב | רוחב | הערה |
|------|------|------|
| כותרת האתר | 68rem (1088px) בנקודת מעבר 64rem; 48rem מתחת | המותג בצד אחד, ניווט וגלולת שפה בצד השני. מיושרת עם דף הבית |
| דף הבית, רשימות | 1048px תוכן (main 42rem בעמודי קריאה) | |
| עמודי קריאה (סיפור, מבט, רגע) | טור 672px, גוף 1.35rem מ-52rem | **לא מרחיבים**: זה אורך שורה נוח |

## כללי ברזל
1. **כותרת אחת לכל עמוד.** מעל 34rem כל עמוד, גם סיפור ומבט לשבת, מציג ניווט מלא ולא ☰. בטלפון ☰ נשאר.
2. **אין סלקטור על תג חשוף ב-CSS גלובלי** (`header`, `nav`, `section`). רק מחלקה (`.site-header`). הכלל הישן על `header` דחס את הכותרת של כל סיפור.
3. **מדף במחשב הוא רשת.** 3 עמודות בדף הבית, 4 בעמוד הסיפורים. בלי גלילה אופקית שחותכת כרטיס. בטלפון נשארת הגלילה.
4. **בלי חורים ברשת.** מספר הכרטיסים מתחלק במספר העמודות (3 חדשים, 6 נקראים בבית; 8 ברשימה). שינוי מספר פריטים מחייב לבדוק את הרשת.
5. **תמונה לא תופסת מסך.** כרטיס "השבוע" 2:1, דיוקן 4:3. שער סיפור נשאר ברוחב הטור.
6. שינוי מחשב מוסיפים ב-`@media (min-width: 52rem)` (או 34rem לכותרת). הטלפון לא משתנה: כל שינוי נבדק גם ב-390.
7. שתי השפות תמיד.

## בדיקה
`npm run build && npm run preview` ואז `npm run qa:visual`. נגד האתר החי: `npm run qa:visual -- https://nekudatmabat.blog`. אוטומטית: `.github/workflows/visual-qa.yml`. הסקיל `desktop-qa` מפעיל ומסכם.
